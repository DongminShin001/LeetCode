## Company Focus Notes
- **Google**: Graphs + DP heavy, clean code with good complexity analysis
- **Meta**: Trees + Arrays + BFS, speed matters
- **Amazon**: OOP design + Arrays + Trees + BFS, edge cases matter
- **Apple**: Binary search + system design
- **Microsoft**: Broad coverage, communication style

---

## Interview Style Reminders
1. Clarify the problem first (ask about edge cases, constraints)
2. State your approach + complexity BEFORE coding
3. Code it cleanly
4. Test with examples (including edge cases)
5. Optimize if time allows
